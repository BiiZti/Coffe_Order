# CMCC Coffee 订单管理系统 - 问题修复说明

## 修复的问题

### 1. 更新前端Excel文件失败:订单编号

**问题描述：**
- Excel文件更新时出现权限错误或文件锁定问题
- 订单编号查找失败
- 文件保存验证失败

**解决方案：**
- 添加了线程锁 `excel_write_lock` 防止并发写入冲突
- 实现了重试机制，最多重试3次
- 改进了错误处理和文件权限检查
- 添加了文件存在性检查
- 优化了订单编号查找逻辑
- 增加了详细的调试日志

**相关文件：**
- `app.py` - `update_excel_order_status_by_number` 函数

### 2. Connection pool is full, discarding connection

**问题描述：**
- Flask默认连接池大小只有1，无法处理并发请求
- 出现 "connection pool is full, discarding connection:localhost. connection pool size: 1" 错误

**解决方案：**
- 创建了配置文件 `config.py` 来管理Flask配置
- 启用了多线程支持 (`threaded=True`)
- 增加了连接池大小配置
- 添加了请求频率限制防止过度请求
- 实现了更好的错误处理中间件

**相关文件：**
- `config.py` - 配置文件
- `app.py` - Flask应用配置和错误处理

## 配置参数说明

### 服务器配置
- `HOST`: 服务器主机地址 (默认: 0.0.0.0)
- `PORT`: 服务器端口 (默认: 5000)
- `THREADED`: 是否启用多线程 (默认: True)
- `PROCESSES`: 进程数 (默认: 1)

### Excel文件配置
- `EXCEL_RETRY_COUNT`: 重试次数 (默认: 3)
- `EXCEL_RETRY_DELAY`: 重试延迟秒数 (默认: 2)
- `EXCEL_LOCK_TIMEOUT`: 文件锁超时秒数 (默认: 30)

### 请求限制
- `REQUEST_RATE_LIMIT`: 请求频率限制秒数 (默认: 5)

## 注意事项

1. **Excel文件权限**：确保Excel文件没有被其他程序打开，且具有写入权限
2. **并发操作**：系统现在支持并发请求，但Excel文件操作会被序列化
3. **错误重试**：Excel文件操作失败时会自动重试，最多3次
4. **请求限制**：同一订单的相同操作在5秒内只能执行一次

## 故障排除

### 如果仍然出现Excel更新失败：
1. 检查Excel文件是否被其他程序打开
2. 检查文件权限（右键 -> 属性 -> 取消只读）
3. 以管理员身份运行程序
4. 查看控制台日志获取详细错误信息

### 如果出现连接池问题：
1. 检查是否有多个实例在运行
2. 重启应用
3. 检查网络连接
4. 查看控制台日志获取详细错误信息
