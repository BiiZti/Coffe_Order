# CMCC Coffee 订单管理系统 - 启动说明

## 启动方式

### 1. 推荐启动方式：使用 start.py
```bash
python start.py
```
- ✅ 推荐使用
- ✅ 包含依赖检查
- ✅ 检查数据文件
- ✅ 不会自动打开浏览器
- ✅ 使用 run.py 作为启动脚本

### 2. 直接启动：使用 run.py
```bash
python run.py
```
- ✅ 直接启动，无额外检查
- ✅ 不会自动打开浏览器
- ✅ 适合开发调试

### 3. 传统启动：使用 main.py
```bash
python main.py
```
- ✅ 自动打开浏览器
- ⚠️ 不推荐与其他启动方式同时使用

## 避免重复打开浏览器

### 问题原因
如果浏览器打开了两次，可能是因为：
1. **运行了两次 `main.py`**（最常见原因）
   - 在两个不同的终端窗口都运行了 `python main.py`
   - 或者在同一个终端运行了两次
2. **Flask的debug模式**（如果启用）
   - 某些情况下Flask debug模式可能会触发额外的浏览器打开
3. **浏览器本身的行为**
   - 某些浏览器可能会自动打开多个标签页

### 解决方案

#### 方案1：只使用 start.py（推荐）
```bash
# 只运行这一个命令
python start.py
```

#### 方案2：使用 main.py 自动打开浏览器
```bash
python main.py
# 会自动打开浏览器
```

#### 方案3：手动访问
```bash
# 运行任意启动脚本
python start.py

# 然后手动在浏览器中访问
http://localhost:5000
```

## 故障排除

### 如果浏览器打开了两次
1. **检查是否有多个终端窗口在运行 `main.py`**
   - 关闭所有运行 `python main.py` 的终端
   - 确保只在一个终端运行
2. **使用任务管理器检查进程**
   - 检查是否有多个Python进程在运行
   - 结束重复的进程
3. **推荐使用 `start.py`**
   - `start.py` 不会自动打开浏览器
   - 手动访问 `http://localhost:5000`

### 如果端口被占用
```bash
# Windows
netstat -ano | findstr :5000
taskkill /PID <进程ID> /F

# 或者使用不同的端口
set FLASK_RUN_PORT=5001
python start.py
```

### 如果依赖缺失
```bash
pip install -r requirements.txt
```

## 注意事项

1. **不要同时运行多个启动脚本**
2. **推荐使用 start.py 作为主要启动方式**
3. **如果需要自动打开浏览器，使用 main.py**
4. **开发调试时可以使用 run.py**
